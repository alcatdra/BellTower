![изображение](https://github.com/alcatdra/BellTower/assets/114382863/67936f4b-849f-4bd5-87e0-e3c44c010a74)# Колокольня VR
Версия редактора Unity - 2021.3.5f1 <br>
Студенческий проект. VR симулятор игры на колоколах в колокольне волгоградского собора Александра Невского.
<br>
Звуки были записаны с колоколов этой колокольни, фотографии города за её пределами вставлены в качестве плейсхолдера. <br>
